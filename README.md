My project partner and I wrote an IMRaD research paper investigating the relationship between estimated house values and the distance to the nearest rail trail. This project was for Applied Linear Models as part of my master's program. Rail trails, former railway lines converted into walking and cycling paths, might be regarded as amenities which raise nearby property values. We had to write a research paper from a consulting perspective for an imaginary company that built a large number of homes and wanted to know the locations upon which it would be most profitable to build. Using realtor data from Northampton, our analysis investigated whether homebuyers were willing to pay more for a house closer to a rail trail. The results of the log-linear multiple regression model in R show that there is insufficient evidence that proximity to rail trails is associated with higher home values. In the conclusion, I commented on the issue of overfitting and suggested that a more parsimonious model might be appropriate for future projects. We received full marks for this project.
